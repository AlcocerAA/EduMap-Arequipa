# EduMap Arequipa

Aplicación web estática en un único archivo HTML (`index.html`), con estilos y JavaScript incluidos.

## Despliegue en Vercel

Importa este repositorio en Vercel y conserva la configuración predeterminada para un proyecto estático:

- Framework preset: **Other**
- Build command: vacío
- Output directory: `.`
- Install command: vacío

Vercel publicará `index.html` como página principal. No se necesita un servidor ni variables de entorno.
